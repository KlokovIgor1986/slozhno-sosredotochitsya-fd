## Задача проекта
Сверстать адаптивный сайт в светлой и тёмной темах согласно макета в фигме.

## Технологии
- HTML
- CSS
- JavaScript

## Функциональность
### Цветовая палитра
- Цветовая схема переключается по нажатию на кнопку в шапке сайта
- Последняя нажатая кнопка остаётся выделенной границами
- При наведении меняется цвет и прозрачность границы выделенной кнопки
- При фокусе кнопка подчёркивается нижней границей
- Смена цветовых схем анимированна
### Адаптивность (зависимость от масштаба и размера страницы)
- Ширина body подстраивается под размеры страницы
- Размеры заголовков в шапке и подвале меняются от масштаба и размера страницы
- Секции и элементы сайта меняют своё позиционирование в зависимости от масштаба и размера страницы

## Особенность
- "Уши" сайта выполнены без фоновой картинки
- Убран скролл при переходах на точках размеров страницы
- Использованны псевдоэлементы для создания декоративных элементов и для настройки фона страницы сайты
